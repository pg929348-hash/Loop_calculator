# 🧮 Python Loop Calculator

A beginner-friendly command-line calculator made with Python. This project was built to practice `while` loops, `if-elif-else` conditions, and `break` statements.

### ✨ Features

- **Basic Operations**: Addition `+`, Subtraction `-`, Multiplication `*`, Division `/`
- **Continuous Calculation**: Runs in an infinite loop until user exits
- **Error Handling**: Prevents `ZeroDivisionError` by checking for division by zero
- **Input Validation**: Shows `invalid operator` message for wrong inputs
- **Exit Command**: Type `exit` to quit the calculator gracefully

### 🚀 How to Run

1. Make sure you have Python 3 installed
2. Clone this repo or download `calculator.py`
3. Run the file in terminal:
   ```bash
   python calculator.py
